# Marvel Unification

RimWorld 1.6 mod with Cyclops, Deadpool and Wolverine, Gambit, Hulk, Jean Grey/Phoenix, Magneto, Multiple Man, Nightcrawler, and Storm.

Place this folder in RimWorld's `Mods` directory and enable Harmony, Biotech, and Marvel Unification in that order. Disable the individual character mods listed in `About/About.xml` to avoid duplicate definitions. The other DLCs are optional.

Build the source with `Source/Build.ps1`. Supply `-CompilerPath`, `-RimWorldDir`, or `-HarmonyPath` if needed, or build `Source/MarvelUnification.csproj` with a .NET SDK and .NET Framework 4.8 reference assemblies. Create a release ZIP with `Source/Package.ps1`.
